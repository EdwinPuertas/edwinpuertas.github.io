## Overview

Apollo is a Python package that provides three unified channels for multimodal AI development: **Audio (Lyre)**, **Text (Pythia)**, and **Vision (Argus)**. It is designed to accelerate the development of complex applications that need to process multiple signal types simultaneously, offering utility functions and pre-integrated AI models across all three channels.

## Channels

### Lyre — Audio
Processes and analyzes audio streams for speech analysis, prosody extraction, and acoustic feature computation. Designed for applications in mental health assessment, voice biometrics, and multimodal affective computing.

### Pythia — Text
NLP pipeline covering tokenization, text classification, sentiment analysis, named entity recognition, and syllabification — with particular strength in Spanish-language tasks. Includes pre-trained models optimized for Latin American Spanish.

### Argus — Vision
Computer vision toolkit featuring:
- **Head Analysis**: Pose estimation and gaze tracking
- **Part Indices**: Body part detection and indexing for motor pattern analysis
- **Facial Movement Analysis**: Action unit detection for affective state inference
- **Statistical Analysis**: Tools for quantifying variability and asymmetry in motion sequences

## Key Features

- **Unified API**: Single import surface for all three modalities, reducing boilerplate and integration complexity
- **Pre-built Models**: Text processing and syllabification models are bundled and ready for inference
- **Diagnostic Tools**: Argus provides complete diagnostics for motor patterns — directly supporting the MentalGuard and Mapping Motion projects
- **Extensible**: Each channel is independently versioned and can be used standalone or in combination

## Applications

- Multimodal mental health risk detection (MentalGuard)
- Dyspraxia movement analysis (Mapping Motion)
- Spanish NLP pipelines for research and industry
- Real-time audio-visual assistants
